## How to use them

1. Click **Open in Colab** next to the notebook.
2. In Colab, choose **File → Save a copy in Drive**: otherwise your work is lost when you close the tab.
3. Run the cells in order. The first cells install `gurobipy` and read the data from the folder [`data`](data) of this repository.

When a notebook is updated with the solutions, open it again from this page: your copy in Drive does not change.
